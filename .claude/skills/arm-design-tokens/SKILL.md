# Визуальный язык АРМ диспетчера ОДС

Контекст: диспетчерская, приглушённый свет, плотная таблица, экран открыт всю
смену. Тёмная тема — основная и по умолчанию, светлая существует как второй
режим (ADR 0009). Полный источник — `ARM-ODS-frontend-spec.md` §4.

## Токены

Определены в `frontend/src/styles/tokens.css` и проброшены в Tailwind через
`@theme` в `frontend/src/index.css`. **Не хардкодить цвета.** Использовать
переменные (`var(--panel)`) или утилиты Tailwind (`bg-panel`, `text-dim`,
`border-line`).

Поверхности: `--bg` `--panel` `--raised` (ховер строки, вложенные блоки)
`--sunken` (поля ввода) `--line` `--line-strong` (границы активных).
Текст: `--text` `--text-dim` `--text-mute`.
Риск (единственный смысловой цвет, холодный → горячий):
`--risk-low` `--risk-medium` `--risk-high` `--risk-critical`.
Управление: `--accent` `--accent-strong` `--accent-hover` (первичная кнопка,
чекбоксы), `--danger` `--danger-strong` `--danger-hover`, `--secondary-hover`.

**Две темы, один набор имён.** Тёмные значения — в `:root`, светлые — в
`:root[data-theme='light']`. Новый токен обязан появиться в обеих, иначе падает
`tokens.test.ts`. Компонент активную тему не знает: никаких `if (theme === ...)`
и никаких `dark:`-вариантов Tailwind — только токен, который сам меняет
значение.

## Правила

- **Уровень риска кодируется дважды**: цветом и вертикальной планкой 3px слева от
  строки/карточки. Только цветом — нельзя (доступность).
- Шрифты: `--font-ui` (Golos Text) для интерфейса; `--font-mono` (JetBrains Mono)
  с `font-variant-numeric: tabular-nums` — класс `.mono` — для ID, времени, чисел
  в таблицах.
- Веса только 400 и 500. Размеры 18/14/13/12. Сентенс-кейс везде.
- `border-radius: 4px` на панелях и контролах, `0` на строках таблицы.
- Теней нет — глубина только фоном.
- Анимация только в ответ на действие пользователя, 120–160 мс.

## Каркас

Шапка 48px (название · свежесть данных · ссылка на API) · слева рельс из 4 иконок
разделов · рабочая зона по маршруту · правая панель 420px с карточкой прогноза
(не модальная, сворачивается, карта под ней остаётся видна).

## Не делать

- Одинаковые скруглённые карточки с мягкой тенью на всё.
- ALL-CAPS подписи над заголовками.
- Градиенты.
- «Большая цифра + мелкая подпись» как герой экрана.
- Стрелки `→` в тексте кнопок.
- Переключатель масштаба.
- Ветвление по теме в коде компонентов и `dark:`-варианты Tailwind: тема
  целиком живёт в значениях токенов.
