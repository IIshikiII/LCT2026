# Точки расширения АРМ диспетчера ОДС

Главный принцип (spec §2): **фронтенд не знает, сколько направлений
прогнозирования существует и как они называются.** Он строит интерфейс по
описанию из `GET /meta`. Изменение ТЗ (новое направление, другой набор полей,
другой список действий) не должно приводить к правкам в экранах.

## Правило «строка, не union»

`Direction`, `level`, `status` типизируются как `string`. Никогда не писать
`type Direction = 'FIRE_RISK' | ...`. **Ни одного `switch` по коду направления
во всём коде** (критерий приёмки). Метки, цвета, пороги — из реестров `meta`.

## Четыре реестра

Каждый — `Record<string, Renderer>` + запасной вариант. Добавление нового
элемента = один файл + одна строка в реестре. До этого момента элемент уже
как-то отображается (запасным рендерером), экран не падает.

| Реестр | Файл | Ключ | Запасной |
|---|---|---|---|
| Блоки карточки | `frontend/src/card/blockRegistry.tsx` | `block.type` | `GenericBlock` (рекурсивно рисует `data` как пары и таблицы) |
| Действия | `frontend/src/card/actionRegistry.tsx` | `action.code` | `DynamicForm` (форма по `action.fields`) |
| Колонки журнала | `frontend/src/table/columnRegistry.tsx` | ключ из `meta.journalColumns` | пропустить колонку |
| Виджеты дашборда | `frontend/src/widgets/widgetRegistry.tsx` | код из `meta.dashboardWidgets` | пропустить виджет |

## Обязательные требования

- Каждый блок карточки обёрнут в `ErrorBoundary` — сломанные данные одного блока
  не уносят карточку.
- `GenericBlock` должен работать на любом JSON.
- `DynamicForm` строит `zod`-схему из `FieldDef[]` (`required`, `minLength`),
  `select.optionsRef` — ключ в `meta.reasons`.
- Состав и порядок колонок/виджетов — строго из `meta`, с запасным списком в
  `frontend/src/shared/config/fallbacks.ts`.
- Флаги экранов в `frontend/src/shared/config/features.ts` —
  выключенный экран пропадает из рельса и роутера.

## Тест на гибкость (критерий приёмки)

Добавить в мок `/meta` новое направление с выдуманным названием. Оно обязано
само появиться в фильтрах журнала, на карте и на дашборде — без правок кода.
Если пришлось что-то править — где-то остался `switch` по коду, убрать.
