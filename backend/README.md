# backend

REST API, конвейер прогноза, модуль заявок, вход и роли. FastAPI и Postgres,
всё работает в Docker.

## Быстрый старт

```
cp .env.example .env
docker compose up -d db api
docker compose run --rm pipeline uv run --no-sync python -m app.cli migrate
curl http://127.0.0.1:8000/healthz
```

Полный порядок запуска с данными и моделями описан в корневом
[`README.md`](../README.md), настоящая выгрузка и поток СМВУ в
[`docs/02-local-run.md`](docs/02-local-run.md).

## Что где

| Папка | Что в ней |
|---|---|
| `app/api/` | Роутеры REST API |
| `app/pipeline/` | Прогон конвейера: прогнозы, уровни, автозаявки |
| `app/ml/` | Плагины направлений и правила пожара |
| `app/features/` | Признаки направлений строго до момента расчёта |
| `app/ingest/` | Загрузчик выгрузки и приём потока |
| `app/stub/` | Заглушка потока СМВУ |
| `app/auth/` | Вход, второй фактор, роли |
| `migrations/` | Миграции SQL |
| `tests/` | Тесты pytest на отдельной базе `arm_test` |
| `artifacts/` | Обученные модели. В git не хранятся |
| `docs/` | Документация сервера. Начинать с [`docs/README.md`](docs/README.md). Решения лежат в [`../docs/adr/`](../docs/adr/README.md) |

Все порты открыты только на `127.0.0.1`. Наружу их открывает
`BIND_HOST=0.0.0.0`. На Ubuntu опубликованный Docker порт обходит `ufw`.
