# Тетради разведочного анализа

Каталог смонтирован в контейнер `research` как корень JupyterLab.

Запуск:

```
docker compose --profile tools up research
```

Затем откройте `http://localhost:8888`.

Правила:

1. Тетрадь не является частью сервиса. Код, который нужен конвейеру, переезжает
   в `app/ml/` или `app/features/`.
2. Выводы тетради записывайте в `../docs/`. Тетрадь хранит ход работы, документ
   хранит результат.
3. Результаты обучения пишите в MLflow на `http://mlflow:5000`. Переменная
   `MLFLOW_TRACKING_URI` уже задана в контейнере.
4. Выгрузки лежат в `/srv/data`, обученные модели в `/srv/artifacts`.
5. Разбиение выборки — только по времени. Спецификация §9.
