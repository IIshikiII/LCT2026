# Документация бэкенда АРМ диспетчера ОДС

Читать в этом порядке. Каждый документ отвечает на один вопрос и не пересказывает
соседние.

| Документ | Отвечает на вопрос |
|---|---|
| [01-dependencies.md](01-dependencies.md) | Из чего собран сервис, почему взята каждая зависимость |
| [02-local-run.md](02-local-run.md) | Как поднять сервис и прогнать проверки |
| [03-database.md](03-database.md) | Как устроена схема и как добавить миграцию |

Целевое состояние сервиса описывает `../../ARM-ODS-backend-spec.md`. Эти
документы описывают текущее состояние и отклонения от спецификации.

## Правило

Сообщение коммита помогает найти место в истории. Оно не хранит знание.
Если объяснение нужно читать через год, его место здесь, а не в коммите.
