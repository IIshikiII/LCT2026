# Заглушки

Стенд-ин бэкенда на MSW. Приложение целиком работает без сервера при
`VITE_USE_MOCKS=true`.

Подробное описание — в [../../docs/04-mocks.md](../../docs/04-mocks.md).
Здесь — короткая памятка.

## Два правила

1. **Домен живёт только здесь.** Слова «пожарный риск», «датчик», «износ»,
   «допуск» встречаются в этой папке и нигде больше. Приложение видит их как
   строки из `GET /meta`.
2. **Отсюда никто не импортирует наружу, и снаружи сюда — только три файла:**
   `src/main.tsx`, `src/test/msw.ts`, `src/test/setup.ts`. Удаление этой папки
   не должно ломать сборку приложения.

Оба правила проверяет `src/architecture.test.ts`.

## Что где

| Файл | Что |
|---|---|
| `handlers.ts` | HTTP-хендлеры, по одному на ручку API |
| `browser.ts` / `node.ts` | воркер для дев-сервера / сервер для Vitest |
| `devFlags.ts`, `DevPanel.tsx` | тумблеры демонстрации: сломать `/meta`, включить пятое направление |
| `db/` | генератор данных: справочники, объекты, прогнозы, заявки, метрики |
| `db/actions.ts` | наборы действий по статусам — уходят в единый эндпоинт |
| `db/geo.ts` | настоящие округа Москвы из OSM и трассы коллекторов внутри них |
| `directions/` | **направления прогнозирования как плагины** |

## География

Округа, их коды и центры — подлинные, из OpenStreetMap под ODbL (ADR 0008).
Трассы коллекторов синтетические, но посчитаны один раз внутри реальных
полигонов с отступом от границы и лежат в `db/geo.ts` готовыми координатами.
Правка `db/geo.ts` вручную бессмысленна: это выгрузка, а не исходник.

Границы для подложки карты лежат отдельно, в `public/geo/`, и в заглушки не
входят — их читает сама MapLibre.

## Добавить направление

1. Новый файл в `directions/`, реализующий `DirectionPlugin`.
2. Строка в `directions/index.ts`.

Всё. Направление появится в `/meta`, в прогнозах, в фильтрах, на карте, на
дашборде и в виджете метрик — **без единой правки за пределами этой папки**.
Именно это проверяет `flexibility.test.tsx`.

## Добавить ручку

Хендлер в `handlers.ts` + данные в `db/`. Плюс путь в
`src/shared/api/endpoints.ts` и схема в `src/shared/api/schemas.ts` — три правки
в одном коммите, см. [../../docs/02-api-contract.md](../../docs/02-api-contract.md).

## Детерминированность

`faker.seed(20260908)` и собственный ГПСЧ в `db/rng.ts`. Все относительные даты
считаются от `NOW` — зафиксированного момента, а не от системных часов. Демо
воспроизводимо, тесты не мигают.
