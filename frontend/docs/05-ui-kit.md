# Визуальный язык и примитивы

Диспетчерская: приглушённый свет, плотная таблица, ничего лишнего. Тёмная тема
единственная.

## Токены

Единственный источник — `src/styles/tokens.css`. В Tailwind они прокинуты через
`@theme` в `src/index.css`, поэтому доступны как утилиты: `bg-panel`,
`text-text-dim`, `border-line`.

```
--bg          #161C22   фон приложения
--panel       #1D242B   панели
--raised      #252E36   строка при наведении, вложенные блоки
--sunken      #10151A   поля ввода
--line        #2E3841   разделители
--line-strong #3E4A55   границы активных элементов
--text        #E4E9ED
--text-dim    #9AA8B4
--text-mute   #6B7883
```

Шкала риска — **единственный смысловой цвет** в интерфейсе. Больше ничего цветом
не кодируется, иначе шкала перестаёт читаться:

```
--risk-low       #3E8C74
--risk-medium    #C89230
--risk-high      #D4602F
--risk-critical  #C43B36
```

Цвет уровня берётся не из захардкоженной карты, а из `meta.riskLevels[].colorVar`
через `levelColor()` в `src/shared/lib/risk.ts`. Неизвестный уровень получает
детерминированный цвет из хеша кода.

### Двойное кодирование

Уровень риска кодируется **дважды**: цветом и вертикальной планкой 3 px слева от
строки (`<RiskBar />`). Только цветом — нельзя: восемь процентов мужчин не различат.

## Типографика

- `Golos Text` — интерфейс. Родная кириллица, читается в плотной таблице.
- `JetBrains Mono` с `tabular-nums` — идентификаторы, время, числа в колонках.
  Класс `.mono` или компонент `<Mono>`.
- Веса только 400 и 500. Размеры только 18 / 14 / 13 / 12.
- Сентенс-кейс везде. ALL-CAPS подписей нет.

## Геометрия

- `border-radius: 4px` на панелях и контролах, `0` на строках таблицы.
- Теней нет: глубина передаётся фоном (`sunken` → `bg` → `panel` → `raised`).
- Анимация только в ответ на действие, 120–160 мс. Ничего не «дышит» само.

## Каркас

```
┌──────────────────────────────────────────────────────────┐
│ Шапка 48px: название · свежесть данных · ссылка на API    │
├────┬─────────────────────────────────┬───────────────────┤
│ Р  │                                 │  Правая панель    │
│ е  │      Рабочая зона               │  420px            │
│ л  │      (по маршруту)              │  карточка         │
│ ь  │                                 │  прогноза         │
│ с  │                                 │  (сворачивается)  │
└────┴─────────────────────────────────┴───────────────────┘
```

Рельс — четыре иконки разделов, состав из `features.ts`. Правая панель **не
модальная**: карта под ней остаётся видна, и это существенно — диспетчер
сопоставляет карточку с положением объекта.

## Примитивы

`src/shared/ui/` — семь штук, больше не нужно.

| Компонент | Назначение |
|---|---|
| `Panel` | Панель с рамкой и опциональным заголовком. Базовая единица компоновки |
| `Button` | `kind`: `primary` \| `secondary` \| `danger` \| `ghost`; `size`: `md` \| `sm` |
| `Badge` | Статус или метка. Нейтральный цвет по умолчанию |
| `RiskBar` | Планка 3 px + опциональная подпись уровня |
| `Field` | Обёртка поля формы: подпись, контрол, ошибка, признак обязательности |
| `EmptyState` | «Ничего не найдено» + подсказка, что поменять в фильтрах |
| `ErrorState` | Ошибка загрузки + кнопка «повторить» |

Плюс служебные: `Mono`, `Spinner`, `Skeleton`, `ErrorBoundary`, `Icon`.

`Icon` — тонкая обёртка над спрайтом `public/icons.svg`. Иконки штриховые, 16 px,
толщина 1.5. Иконку без подписи ставим только в рельсе, там есть `title`.

## Доступность

Обязательный минимум, он же проверяется на демо:

- Полный цикл «прогноз → подтверждение заявки → закрытие с разметкой» проходится
  **с клавиатуры**. Строка таблицы — `<tr tabIndex={0}>` с обработчиком `Enter`.
- Правая панель закрывается по `Escape`.
- У всех интерактивных элементов видимый фокус (`outline` цвета `--line-strong`).
- `aria-live="polite"` на области, куда прилетает результат действия.

## Запрещено

Не потому что вкусовщина, а потому что это визуальные штампы, которые сразу
выдают шаблон:

- одинаковые скруглённые карточки с мягкой тенью на всё;
- ALL-CAPS подписи над заголовками;
- градиенты;
- «большая цифра + мелкая подпись» как герой экрана;
- стрелки `→` в тексте кнопок;
- эмодзи в интерфейсе.
