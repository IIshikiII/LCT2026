# Архитектура

## Одна фраза

Фронтенд не знает предметную область. Он получает её описание из `GET /meta` и
строит интерфейс по описанию.

Практическое следствие: слова «пожарный риск», «отказ датчика», «подтопление» не должны
встречаться ни в одном файле вне `src/mocks/`. Проверяется тестом
`src/architecture.test.ts`.

## Слои

```
                        ┌───────────────────────────┐
   HTTP / MSW  ───────► │  shared/api               │  границы контракта
                        │  endpoints · schemas ·    │  всё, что знает про URL
                        │  client · queries         │  и форму ответа
                        └────────────┬──────────────┘
                                     │  типы + хуки TanStack Query
                        ┌────────────▼──────────────┐
                        │  реестры                  │  точки расширения
                        │  blockRegistry            │  сопоставляют строку из
                        │  actionRegistry           │  API компоненту
                        │  columnRegistry           │
                        │  widgetRegistry           │
                        └────────────┬──────────────┘
                                     │
      ┌──────────────────────────────┼──────────────────────────────┐
      │                              │                              │
┌─────▼──────┐              ┌────────▼────────┐            ┌────────▼───────┐
│  screens/  │              │     card/       │            │    table/      │
│  4 экрана  │              │  правая панель  │            │   DataTable    │
└─────┬──────┘              └────────┬────────┘            └────────┬───────┘
      │                              │                              │
      └──────────────────────────────┼──────────────────────────────┘
                                     │
                            ┌────────▼────────┐
                            │   shared/ui     │  Panel, Button, Badge,
                            │   примитивы     │  RiskBar, Field, состояния
                            └─────────────────┘
```

Правило зависимостей: стрелки идут только вниз. `shared/ui` не знает о прогнозах,
`shared/api` не знает о React-компонентах, экраны не импортируют друг друга.

## Поток данных

1. `main.tsx` при `VITE_USE_MOCKS=true` поднимает воркер MSW и только потом
   монтирует React. Это единственное место, где приложение знает о заглушках.
2. `app/providers.tsx` создаёт `QueryClient` с `refetchInterval: 60_000`
   и `staleTime: 30_000`.
3. `app/AppShell.tsx` первым делом дёргает `useMeta()`. Пока `/meta` не пришла,
   показывается скелет. Если `/meta` сломана — берётся `FALLBACK_META` из
   `shared/config/fallbacks.ts`, и приложение поднимается как ни в чём не бывало.
4. Экран читает фильтры из URL (`shared/lib/urlState.ts`), передаёт их в хук
   `usePredictions(filters)`, получает страницу и рисует `DataTable` с колонками
   из `meta.journalColumns`.
5. Клик по строке пишет `?prediction=<id>` в URL. `AppShell` видит параметр,
   грузит `PredictionDetail` и рисует правую панель.
6. Тело карточки — `blocks.map(...)`. Каждый блок проходит через `BlockRenderer`,
   который ищет компонент в `blockRegistry` и оборачивает его в `ErrorBoundary`.
7. Кнопка действия раскрывает форму, собранную по `action.fields`. Отправка идёт
   в `POST /predictions/{id}/actions/{code}`. Ответ — обновлённый `PredictionDetail`,
   он же кладётся в кэш Query.

## Устойчивость: три уровня защиты

Бэкенд на хакатоне меняется каждые два часа. Фронт не имеет права падать.

| Что сломалось | Что происходит | Где реализовано |
|---|---|---|
| Лишнее/переименованное поле в ответе | Разбор проходит, лишнее сохраняется, недостающее логируется в консоль, данные возвращаются как есть | `shared/api/client.ts` → `parseTolerant()` |
| `/meta` недоступна или мусор | Приложение стартует на `FALLBACK_META` | `shared/config/fallbacks.ts` |
| Неизвестный тип блока карточки | Рисуется `GenericBlock` — рекурсивный рендер любого JSON | `card/blockRegistry.tsx` |
| Блок бросил исключение при рендере | Падает только этот блок, остальная карточка жива | `shared/ui/ErrorBoundary.tsx` |
| Неизвестный код действия | Рисуется обычная кнопка + `DynamicForm` по `fields` | `card/actions/actionRegistry.tsx` |
| Неизвестная колонка в `meta.journalColumns` | Молча отбрасывается | `table/columnRegistry.tsx` → `resolveColumns()` |
| Неизвестный код виджета дашборда | Рисуется `GenericWidget`-заглушка с кодом | `widgets/widgetRegistry.tsx` |
| Неизвестное направление или уровень риска | Синтезируется мета: подпись = код, цвет = детерминированный хеш кода | `shared/lib/risk.ts` |

Последняя строка — то, из-за чего новое направление появляется само.

## Чего в архитектуре нет и почему

- **Глобального стора.** Всё состояние UI — в URL, все серверные данные — в кэше
  TanStack Query. См. [adr/0001-no-global-store.md](adr/0001-no-global-store.md).
- **WebSocket.** Горизонт прогноза ≥ 24 ч, опрос раз в минуту избыточен уже.
  См. [adr/0005-polling-not-websocket.md](adr/0005-polling-not-websocket.md).
- **Слоёв FSD.** Пять плоских папок вместо `entities/features/widgets/pages`.
  На 4 экранах слои дают больше церемонии, чем пользы.
- **UI-библиотеки.** Нужно семь примитивов, они написаны в `shared/ui` за вечер
  и не тянут за собой чужую дизайн-систему.
- **Виртуализации таблиц.** Пагинация серверная по 50 строк.
