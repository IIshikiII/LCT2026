# Сценарий показа

Документ описывает, как войти в интерфейс, что смотреть на экранах и как
пройти сценарий за две минуты. Запуск описан в корневом
[`README.md`](../../README.md).

## Вход

Вход идёт в два шага: пароль, затем одноразовый код.

| Логин | Пароль | Роль | Что видит |
|---|---|---|---|
| `ods` | `collector` | Диспетчер ОДС | всё предприятие |
| `district` | `collector` | Диспетчер района | комплексы своего района |
| `tech` | `collector` | Техник | один комплекс, только чтение |
| `crew` | `collector` | Группа реагирования | закрывает заявки отметкой о факте |

Код второго шага настоящий и на заглушках тоже. Первый вход каждой записи
показывает QR-код. Наведите на него камеру приложения-аутентификатора, и оно
заведёт запись само. Подойдёт любое приложение с TOTP: Яндекс Ключ, Google
Authenticator, Microsoft Authenticator, 1Password, Bitwarden, Aegis, KeePassXC.

Под строкой «Камера не берёт код» лежат запасные пути: ключ для ручного ввода и
ссылка `otpauth://`.

### Панель тестового стенда

Сервер с `TEST_STAND=true` показывает справа от формы входа наборы учётных
записей. Набор это четыре роли разом. Занятый набор помечен «2FA пройдена».
Кнопка внизу заводит следующий набор: `ods-2`, `district-2` и так далее.

Флаг раздаёт логины и пароли любому, кто открыл страницу входа. В промышленной
установке его не включают.

## Экраны

| Экран | Адрес | Что показывает |
|---|---|---|
| Дашборд рисков | `/` | Счётчики по уровням и направлениям, топ-10 объектов, соответствие метрикам ТЗ |
| Карта объектов | `/map` | Трассы коллекторов, точки по уровню риска с кластеризацией. Клик открывает карточку |
| Журнал прогнозов | `/journal` | Основная рабочая таблица: фильтры, сортировка, выгрузка в CSV |
| Заявки | `/orders` | Что система создала сама и что с этим стало |

Фильтры и выбранная карточка живут в адресной строке. Ссылку на текущее
состояние можно отправить коллеге.

## Дев-панель заглушек

Кнопка **«моки»** стоит в правом нижнем углу при `VITE_USE_MOCKS=true`.

- **Новое направление** добавляет направление вне базового набора. Оно само
  появляется в фильтрах, на карте и на дашборде.
- **Сломать `/meta`** выключает описание предметной области. Приложение
  работает на запасных настройках и пишет об этом в шапке.
- **Ошибки списков** и **медленная сеть** показывают состояния ошибки и
  загрузки.

## Сценарий на две минуты

1. Откройте дашборд. Виджет «Здоровье модели» сравнивает Precision и Recall
   модели с правилом «событие было вчера». Виджет «Конвейер расчёта» показывает
   время расчёта, горизонт и задержку потока.
2. Откройте журнал и отфильтруйте критический уровень.
3. Откройте строку. Справа появится карточка: вклад признаков, телеметрия,
   история объекта.
4. Перейдите по плашке автоматической заявки в карточке.
5. Нажмите «Взять в работу», затем «Принять решение» и назовите уровень.
   Уровни «Высокий» и «Критический» подтверждают заявку, «Низкий» и «Средний»
   закрывают прогноз без выезда.
6. В заявке нажмите «Назначить бригаду» и задайте срок.
7. Войдите как `crew` и закройте заявку отметкой «факт подтверждён на
   объекте».
8. Войдите как `tech` и откройте журнал. Экран покажет один комплекс и ни одной
   кнопки.
9. В дев-панели включите новое направление и вернитесь на дашборд.

Весь сценарий проходится с клавиатуры.

## Файл окружения

`npm run dev` работает без файла: значения по умолчанию лежат в коде. Чтобы
поменять их, скопируйте `.env.example` в `.env`.

| Переменная | По умолчанию | Зачем |
|---|---|---|
| `VITE_USE_MOCKS` | `true` | Поднимать заглушки. `false` направляет запросы в настоящий API |
| `VITE_API_BASE_URL` | `/api/v1` | База REST API |
| `VITE_API_DOCS_URL` | `/api/v1/docs` | Ссылка на OpenAPI в шапке |
| `VITE_MAP_STYLE_URL` | пусто | Внешняя подложка карты. Пусто значит офлайн-стиль без обращений в сеть |

## Если что-то не работает

| Что видно | Что сделать |
|---|---|
| `npm install` падает на сети | Задайте реестр: `npm config set registry https://registry.npmjs.org/` |
| Пустой экран, в консоли ошибки MSW | Создайте воркер заглушек: `npx msw init public/` |
| На карте нет улиц | Так задумано: подложка не грузится из сети. Улицы включает `VITE_MAP_STYLE_URL` |
| Кириллица системным шрифтом | Нет доступа к Google Fonts. На работу это не влияет |
