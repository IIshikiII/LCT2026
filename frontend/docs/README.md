## Правила работы с этой документацией

Документация — часть кода, а не приложение к нему. Три следствия:

1. **Изменил контракт API — правь [02-api-contract.md](02-api-contract.md) в том же
   коммите.** Расхождение документа и кода дороже отсутствия документа.
2. **Добавил точку расширения — опиши её в [03-extension-points.md](03-extension-points.md).**
   Следующий разработчик найдёт её только там.
3. **Принял решение, которое кто-то захочет оспорить — заведи ADR.** Дешевле один раз
   написать «почему нет WebSocket», чем объяснять это трижды.

## Быстрая навигация по коду

```
src/
  app/       каркас: шапка, рельс, роутер, правая панель, провайдеры
  screens/   четыре экрана: dashboard, map, journal, orders
  card/      карточка прогноза и заявки — общий модуль для map, journal, orders
  table/     DataTable и реестр колонок
  widgets/   виджеты дашборда и их реестр
  shared/    api / ui / lib / config — всё, что переиспользуется
  mocks/     ЗАГЛУШКИ: MSW + генератор данных по четырём направлениям
  test/      настройка Vitest и хелперы рендеринга
```

Заглушки полностью изолированы в `src/mocks/`. Ни один файл вне этой папки не
импортирует из неё — кроме одной строки в `src/main.tsx`, которая подключает
воркер MSW при `VITE_USE_MOCKS=true`. Удаление папки `src/mocks/` не должно ломать
сборку приложения на реальном бэкенде.
