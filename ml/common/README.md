# ml/common

Общий код направлений. Сейчас здесь один модуль `calendar_ru.py`: календарь
России с праздниками, выходными и школьными каникулами. Календарь строится из
правил без обращения к сети. Скрипты направлений добавляют эту папку в
`sys.path` и берут признаки календаря отсюда.

## Дальнейшие шаги развития проекта

Добавить переносы выходных по постановлениям правительства и перенести сюда
общие правила разметки событий.
