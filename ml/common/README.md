# ml/common

Общий код направлений.

`prepare_inputs.py` собирает входные файлы всех направлений:
`eda/out/events.parquet` с журналом целиком и `eda/out/channels.parquet` со
справочником каналов, где из названия датчика разобраны пикет, смещение и
галерея. Запуск из корня репозитория:
`.venv/bin/python ml/common/prepare_inputs.py`. Журнал собирается примерно за
23 секунды и дальше не пересобирается, справочник примерно за 15 секунд.

`calendar_ru.py` это календарь России с праздниками, выходными и школьными
каникулами. Календарь строится из правил без обращения к сети. Скрипты
направлений добавляют эту папку в `sys.path` и берут признаки календаря
отсюда.
