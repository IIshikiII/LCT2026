# Итерация планирования

Незакрытых задач в `loop/BACKLOG.md` не осталось, а время цикла ещё есть.

## Шаг 1. Оцени, где цель

Прочитай `loop/GOAL.md` и раздел «Что сделать». Проверь каждый из шести
пунктов готовности по репозиторию, а не по журналу. Журнал говорит о намерении,
репозиторий о результате.

Проверяй так:

| Пункт | Чем проверить |
|---|---|
| модель бьёт наивную планку | `ml/access/out/metrics.json` |
| SHAP в карточке | `explain()` плагина и тест на него |
| протокол реализован | `backend/tests/test_plugin_access.py` |
| конвейер пишет прогнозы | прогон команды и запрос в базу |
| фронт рисует объяснение | тест компонента |
| ворота зелёные | `loop/gates.ps1` |

## Шаг 2. Выбери одно из двух

**Цель достигнута.** Допиши в `loop/BACKLOG.md` раздел «Улучшения» и поставь
туда задачи, которые поднимают качество: ещё признаки, калибровка вероятности,
устойчивость к отсутствию данных, замер на втором направлении. Каждая задача с
номером и тегом модели.

**Цель не достигнута.** Найди, чего не хватает, и поставь задачи именно на это.
Крупное дели на куски по одной итерации.

Ставь от трёх до восьми задач. Больше не надо: следующая итерация планирования
поставит ещё.

## Шаг 3. Запиши

Допиши в `loop/JOURNAL.md`:

```markdown
## PLAN · 2026-09-17 18:00 · opus

**Проверено.** Какие пункты готовности закрыты, какие нет.

**Поставлено.** Сколько задач и о чём.
```

Закоммить:

```
git add -A
git commit -m "дополнить план работ цикла"
```

Остановись. Новую задачу не начинай.
