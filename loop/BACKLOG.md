# План работ цикла

Драйвер берёт **первую незакрытую задачу сверху**. Формат строки менять нельзя:
драйвер разбирает её регулярным выражением.

```
- [ ] **T07** `opus` — краткая формулировка
```

Метки: `[ ]` в работе, `[x]` сделано, `[-]` отменено. Тег модели `opus` или
`sonnet` выбирает драйвер для итерации.

Задачу разрешено разбить: замени строку на две с новыми номерами `T07a`, `T07b`
и сделай первую. Задачу разрешено добавить в конец. Порядок менять можно, если
обоснование уходит в журнал.
